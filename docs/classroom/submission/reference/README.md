# Reference material for the poster

- `organisers-guide-2570.pdf` (and a PNG render): the organisers' guide for entrants, as
  received from the team in November 2026.
- `sandstory-example.png`: the example poster ("SandStory") shown in that guide, cropped from
  the guide's raster. It is low resolution because the guide only shows a thumbnail.

What to take from the example: one big illustrated scene carries the story; text sits in small
blocks around it; the steps are numbered over the picture; the "use and benefits" sit in a band
of icons at the bottom; the names and contacts form a small footer. It is visual first.
