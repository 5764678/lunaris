## Poster

- Template: `poster-template-students.pdf` in this folder. Its header reads
  "ประเภทนักเรียน • Students". The file arrived named `TMP_Poster-….TeacherEducator..pdf`;
  the name is wrong or generic, the page is the student one.
- The template page is **A3-sized** (840.9 × 1189.2 pt) and is a raster image. It has the
  same proportions as A0, so the finished poster is exported at A0 with the template
  scaled up 2.83 times.
- Fill in the level box at the top right (ระดับ • CATEGORIES): มัธยมศึกษา.
- Required content, as listed in the guide:
  - name and logo of the institution;
  - name and picture of the work;
  - background, objectives, features;
  - how it works, strengths, what is new;
  - use and benefits;
  - inventors' names, phone number, email.

## Judging criteria

1. Creativity and problem-solving design
2. Appropriate use of technology
3. Potential for real use and for commercial development
4. Quality of the presentation
