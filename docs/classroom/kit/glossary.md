# อภิธานศัพท์ ไทย–อังกฤษ

คำศัพท์ที่ใช้ในชุดกิจกรรมและในแอป LUNARIS

**คำที่ทำเครื่องหมาย `ตรวจสอบ`** คือคำที่ผู้ร่างไม่แน่ใจว่าตรงกับพจนานุกรมศัพท์ดาราศาสตร์ของราชบัณฑิตยสภา
หรือหนังสือเรียนวิทยาศาสตร์ ม.3 ของ สสวท. ทีมและครูที่ปรึกษาต้องตรวจก่อนใช้ แล้วแจ้ง S-CLASSROOM และ S-DESIGN
ให้ใช้คำเดียวกันในแอป (คำในแอปยังอยู่ระหว่างแปล)
