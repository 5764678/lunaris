## ตอนที่ 4 คณิตศาสตร์ของขอบหลุม

> **ตัวเลขในตอนนี้เป็นตัวเลขสมมุติเพื่อฝึกคำนวณ ไม่ใช่ข้อมูลจริงของหลุมใด**

ผู้สังเกตยืนบนพื้นหลุม ขอบหลุมสูงกว่าระดับสายตา h และอยู่ห่างออกไปในแนวราบ d มุมเงยของขอบหลุม θ หาได้จาก

```
tan θ = h / d        θ = arctan(h / d)
```

```
                     ขอบหลุม
                    /|
                   / |
                  /  | h
                 /θ  |
   ผู้สังเกต  ●------+
                 d
```
