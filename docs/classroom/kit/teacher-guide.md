## 2. แอปทำอะไร และไม่ทำอะไร

**โหมดห้องเรียน (`/learn`)** มี 6 ขั้นตามคาบ อ่านตัวเลขจากชุดข้อมูลบทเรียนที่คำนวณไว้ล่วงหน้าจากโค้ดและข้อมูลจริงของ LUNARIS
(ข้อมูลภูมิประเทศ LOLA และเรขาคณิต SPICE ของ NASA) จึงไม่ต้องรอเซิร์ฟเวอร์คำนวณระหว่างคาบ ตัวเลขทุกตัวมีป้ายหลักฐาน
บอกชนิด วิธี แหล่งข้อมูล และข้อจำกัด หน้า Explorer อื่น ๆ (เช่น Compare, Terrain) ใช้เซิร์ฟเวอร์จริง ซึ่งอาจช้าเมื่อเพิ่งตื่น

| แอปแสดง                                                                                                                 | แอป**ไม่**แสดง / ไม่ทำ                                                                              |
| ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| ข้างขึ้นข้างแรมตลอดหนึ่งรอบเดือน ร้อยละของส่วนสว่าง ข้างขึ้นหรือข้างแรม ชื่อไทย                                         | ภาพดวงจันทร์ตามที่ผู้สังเกตในไทยเห็น (แอปมองจากจุดศูนย์กลางโลก ทิศเหนืออยู่ด้านบน)                  |

| สัดส่วนเวลาที่ได้รับแสงและที่มองเห็นโลก ของสามจุดสาธิตปี 2570                                                           | น้ำขึ้นน้ำลง (สอนด้วยกิจกรรม unplugged ในคาบที่ 3)                                                  |
| ตารางเปรียบเทียบ การครอบงำ และคำแนะนำหนึ่งจุดจากความต้องการของภารกิจ (มีคำแนะนำเริ่มต้นก่อนตอบ) น้ำหนักติดป้ายข้อสมมุติ | วันทางจันทรคติ (ค่ำ) แสงโลก หรือเส้นทางดวงอาทิตย์ของกรุงเทพฯ                                        |
|                                                                                                                         | การสื่อสารทางวิทยุจริง (การมองเห็นโลกเป็นเชิงเรขาคณิตเท่านั้น)                                      |
|                                                                                                                         | คำตอบที่ถูกของการเลือกจุด (คำแนะนำเป็นข้อกล่าวอ้างให้ตรวจ) และเรื่องความร้อน ฝุ่น ทรัพยากร วิถีโคจร |

แอปมีจุดที่เผยแพร่แล้ว 27 จุด ชุดนี้ใช้สามจุดสาธิต (ยอดเขาใกล้แชคเคิลตัน สันเขาเชื่อมต่อ เทือกเขามาลาเพิร์ต) ให้ใบงานสั้นพอ
คำถามความต้องการของภารกิจอยู่ในหน้า Compare ซึ่งใช้เซิร์ฟเวอร์จริง ตรวจว่าขั้นที่ 5 ของโหมดห้องเรียนมีคำถามนี้ด้วยหรือไม่ (ตรวจสอบ)

ข้อควรพูดให้ตรง: จุดในแอปเป็นจุดกึ่งกลางของช่องข้อมูล ไม่ใช่จุดลงจอดที่เลือกแล้ว เงาในภาพสามมิติเป็นภาพประกอบ
ข้อความอธิบายวิธีและข้อจำกัดในป้ายหลักฐานยังเป็นภาษาอังกฤษ (ใต้หัวข้อภาษาไทย) และแอปไม่ได้แทนแบบจำลองหลอดไฟ–ลูกบอล
ซึ่งเป็นหลักฐานของคำว่า "สร้างแบบจำลอง" ในตัวชี้วัด

## 4. ถ้าอินเทอร์เน็ตใช้ไม่ได้

ชุดข้อมูลบทเรียนมากับหน้าเว็บ ถ้าเปิดหน้าเว็บได้ บทเรียนทำงานต่อได้แม้เซิร์ฟเวอร์คำนวณหลับ
แต่**ถ้าเปิดหน้าเว็บไม่ได้เลย** ให้ใช้ชุดสำรองที่เตรียมไว้ล่วงหน้า:

1. **คาบที่ 1 และ 3** ไม่ต้องใช้อินเทอร์เน็ตอยู่แล้ว
2. **คาบที่ 2** บัตรข้อมูล 8 ใบ แต่ละใบมีวันที่ ร้อยละของส่วนสว่าง ข้างขึ้นหรือข้างแรม ชื่อไทย และภาพหน้าจอ
   (ค่าทั้ง 8 แถวอยู่ใน[เฉลยใบงานที่ 1](worksheet-1-answer-key.md) ชื่อข้างขึ้นข้างแรมและภาพหน้าจอต้องเตรียมจากแอปเอง) นักเรียนเรียงบัตรตามวันที่แล้วกรอกใบงานที่ 1
3. **คาบที่ 4** ภาพหน้าจอแผนภูมิท้องฟ้าของจุดยืน พิมพ์สีกลุ่มละ 1 แผ่น (ตารางในใบงานที่ 2 ตอนที่ 3 พิมพ์อยู่แล้ว) ส่วนคณิตศาสตร์ทำได้ตามปกติ
4. **คาบที่ 5** บัตรข้อมูลของสามจุด (ค่าทั้ง 7 ค่าในเฉลยใบงานที่ 3 พร้อมชนิดป้ายหลักฐานและข้อจำกัด) และบัตรคำแนะนำของแอป (คำแนะนำเริ่มต้น และเมื่อนับเฉพาะการลงจอด พร้อมเหตุผล สิ่งที่ต้องยอมเสีย และสิ่งที่ทำให้เปลี่ยน)
5. **คาบที่ 6** ไม่ต้องใช้อินเทอร์เน็ต

ค่าในชุดสำรองต้องคัดจากชุดข้อมูลบทเรียนตรง ๆ ห้ามพิมพ์ค่าประมาณ และระบุบนบัตรว่าเป็นข้อมูลรอบเดือนหรือปีใด

## 5. ความปลอดภัยและความเป็นส่วนตัว

- หลอดไฟอาจร้อน ห้ามจ้องหลอดไฟ ระวังสายไฟในห้องมืด
- แอปไม่มีบัญชีนักเรียนและไม่ต้องเข้าสู่ระบบ ใช้รหัสนักเรียนแทนชื่อบนแบบทดสอบและใบงาน
- ถ้าจะใช้คะแนนหรือผลงานนักเรียนเป็นข้อมูลวิจัยหรือเผยแพร่ ต้องได้รับความยินยอมจากนักเรียนและผู้ปกครอง และอนุญาตจากโรงเรียนก่อน
