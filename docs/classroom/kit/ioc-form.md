## คำชี้แจง

พิจารณาความสอดคล้องของแต่ละรายการกับจุดประสงค์หรือตัวชี้วัดที่ระบุ แล้วทำเครื่องหมาย ✓ ในช่องคะแนน

| คะแนน | ความหมาย            |
| ----- | ------------------- |
| +1    | แน่ใจว่าสอดคล้อง    |
| 0     | ไม่แน่ใจว่าสอดคล้อง |
| −1    | แน่ใจว่าไม่สอดคล้อง |

ถ้าให้ 0 หรือ −1 โปรดเขียนข้อเสนอแนะ

**การคำนวณ (สำหรับทีม)** IOC = ΣR / N เมื่อ ΣR คือผลรวมคะแนนจากผู้เชี่ยวชาญทุกคน และ N คือจำนวนผู้เชี่ยวชาญ
เกณฑ์ที่ใช้คัดเลือก [ทีมกำหนดและอ้างอิงแหล่งที่ตรวจแล้ว แนวปฏิบัติที่พบบ่อยในงานวิจัยไทยคือ 0.50 ขึ้นไป]
