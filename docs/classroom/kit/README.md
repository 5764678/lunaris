# ชุดกิจกรรมการเรียนรู้ LUNARIS ห้องเรียนภารกิจดวงจันทร์ (ฉบับร่าง v1)

> **สถานะ:** ฉบับร่างสำหรับครูที่ปรึกษาตรวจแก้ ยังไม่ได้ทดลองใช้กับนักเรียน
> ไม่มีผลการทดลองใช้ใด ๆ ในเอกสารชุดนี้ ครูที่ปรึกษาเป็นผู้ตรวจแก้และเป็นเจ้าของเอกสารฉบับสุดท้าย

ชุดกิจกรรมการเรียนรู้แบบสืบเสาะหาความรู้ (5E) สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3 จำนวน 6 คาบ คาบละ 50 นาที
ใช้แบบจำลองหลอดไฟ–ลูกบอล กิจกรรมไม่ใช้อุปกรณ์ไฟฟ้า (unplugged) และโหมดห้องเรียนของ LUNARIS (`/learn`)
ซึ่งอ่านข้อมูลจากชุดข้อมูลบทเรียน (lesson pack) ที่คำนวณไว้ล่วงหน้าจากข้อมูลของ NASA

## สิ่งที่ซอฟต์แวร์ทำและไม่ทำ (ต้องพูดให้ตรงทุกครั้ง)

- ซอฟต์แวร์ **ไม่มี** แบบจำลองน้ำขึ้นน้ำลง เรื่องน้ำขึ้นน้ำลงสอนด้วยกิจกรรม unplugged ในคาบที่ 3
- ซอฟต์แวร์ **ไม่แสดง** เวลาดวงจันทร์ขึ้นและตกสำหรับผู้สังเกตในประเทศไทย
- ภาพข้างขึ้นข้างแรมในแอปเป็นภาพ **มองจากจุดศูนย์กลางโลก ทิศเหนืออยู่ด้านบน**
  ไม่ได้แสดงการเอียงของเสี้ยวดวงจันทร์ที่ผู้สังเกตในไทยเห็นจริง
- ตัวชี้วัด ว 3.1 ม.3/2 และ ม.3/3 ใช้คำว่า "สร้างแบบจำลอง" คาบที่ 1–2 จึงใช้แบบจำลองหลอดไฟ–ลูกบอลที่นักเรียนสร้างเอง
  ซอฟต์แวร์ใช้ตรวจสอบและขยายแบบจำลอง ไม่ได้ใช้แทน
- วันทางจันทรคติ (ค่ำ) เป็นข้อตกลงของปฏิทิน แอปไม่ได้คำนวณ และอาจต่างจากข้างขึ้นข้างแรมทางดาราศาสตร์ได้หนึ่งวัน

## รายการที่ต้องให้คนตรวจ (รวมจากทุกไฟล์)

1. **ค่าจากชุดข้อมูลบทเรียน** เติมแล้วจาก `apps/web/public/lesson-pack/v1/` (ฉบับ 17 พ.ย. 2569) แต่ละไฟล์ระบุไฟล์ต้นทางของค่า
   สิ่งที่ชุดข้อมูลไม่มี ยังต้องตรวจกับหน้าจอแอป: ชื่อข้างขึ้นข้างแรมที่แอปแสดง จุดที่ขั้นที่ 4 ใช้
   ผลเมื่อตั้งข้อจำกัดบังคับ และค่ำในปฏิทินจันทรคติ ชุดข้อมูลไม่มีจุดที่ได้รับแสง 0 % ใบงานที่ 2 ตอนที่ 3 จึงเปลี่ยนเป็นการเทียบผลของภูมิประเทศ
2. **คำศัพท์ที่ทำเครื่องหมาย `ตรวจสอบ`** ใน [glossary.md](glossary.md) ต้องเทียบกับพจนานุกรมศัพท์ดาราศาสตร์
   ของราชบัณฑิตยสภาและหนังสือเรียน สสวท. ชั้น ม.3
3. **ข้อความมาตรฐาน ค 2.2 และ ค 3.1** ไม่มีอยู่ในบันทึกการเทียบหลักสูตร ครูต้องเติมจากเอกสารหลักสูตร
4. **ข่าวภารกิจฉางเอ๋อ 7 และ CE-7 MATCH** ในคาบที่ 1 ต้องตรวจกับข่าวล่าสุดของ สดร. ก่อนสอน
5. **ข้อความบนหน้าจอโหมดห้องเรียน** (ชื่อปุ่ม ชื่อข้างขึ้นข้างแรม ค่าที่แสดง) ร่างตามแผนงาน K-04 และ K-05
   ต้องเทียบกับหน้าจอจริงเมื่อ S-CLASSROOM ส่งงานแล้ว
6. **เกณฑ์ผ่าน** ในแผนการจัดการเรียนรู้แต่ละแผนเว้นไว้ให้ครูกำหนด
