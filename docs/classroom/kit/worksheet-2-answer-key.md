| ข้อ 2.3 | มีช่วงที่ดวงอาทิตย์อยู่ใต้เส้นขอบฟ้าหรือไม่ และทิศใด `[รอค่าจากชุดข้อมูลบทเรียน]`             |
| ข้อ 2.4 | ช่วงมุมเงยและทิศของโลก `[รอค่าจากชุดข้อมูลบทเรียน]`                                           |

| ข้อ 4.5 | ขึ้นกับค่าในข้อ 3.1 `[รอค่าจากชุดข้อมูลบทเรียน]`                                              |

ยอมรับค่าที่อ่านจากแผนภูมิได้ใกล้เคียงค่าจริง ครูกำหนดช่วงที่ยอมรับเมื่อได้ค่าจริงแล้ว (การอ่านจากกราฟไม่แม่นเท่าตัวเลข)

## ตอนที่ 1 คำทำนาย

ไม่ให้คะแนนความถูกต้อง คำตอบที่คาดหวังหลังเรียน: กรุงเทพฯ ดวงอาทิตย์ขึ้นทางตะวันออก ขึ้นสูงกลางวัน ตกทางตะวันตก
ขั้วใต้ของดวงจันทร์ ดวงอาทิตย์วนรอบขอบฟ้าอยู่ต่ำมาก ใช้เวลาประมาณหนึ่งเดือนของโลกต่อหนึ่งรอบ

## ตอนที่ 2 อ่านแผนภูมิท้องฟ้า

- 2.1 `[รอค่าจากชุดข้อมูลบทเรียน]` ข้อสังเกตที่ต้องได้: ดวงอาทิตย์อยู่ต่ำมาก ใกล้ 0 องศาตลอด
- 2.2 **วนรอบขอบฟ้าอยู่ต่ำ ๆ**
- 2.3 `[รอค่าจากชุดข้อมูลบทเรียน]`
- 2.4 `[รอค่าจากชุดข้อมูลบทเรียน]` ข้อสังเกตที่ต้องได้: โลกอยู่ต่ำใกล้ขอบฟ้า
- 2.5 ดวงอาทิตย์วนไปรอบทุกทิศ ส่วนโลกอยู่ในทิศเกือบเดิม ขยับขึ้นลงเพียงเล็กน้อย
  เพราะดวงจันทร์หันด้านเดียวเข้าหาโลก (หมุนรอบตัวเองหนึ่งรอบต่อการโคจรรอบโลกหนึ่งรอบ)
  การที่โลกขยับขึ้นลงเล็กน้อยเกิดจากการแกว่งของดวงจันทร์ (ไม่ต้องให้นักเรียนรู้ชื่อนี้)

## ตอนที่ 3 พื้นหลุม

- 3.1–3.2 `[รอค่าจากชุดข้อมูลบทเรียน]`
- 3.3 **เกณฑ์ (3 คะแนน)**

| คะแนน | ลักษณะคำตอบ                                                                                                                                                                              |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3     | ดวงอาทิตย์อยู่ต่ำใกล้ขอบฟ้าเสมอ ขอบหลุมสร้างเส้นขอบฟ้าที่สูงกว่ามุมเงยของดวงอาทิตย์ในทุกทิศ แสงจึงส่องไม่ถึงพื้นหลุม ส่วนยอดเขาสูงกว่าสิ่งรอบข้าง เส้นขอบฟ้าต่ำ จึงเห็นดวงอาทิตย์ได้บ่อย |
| 2     | บอกว่าขอบหลุมบังแสง แต่ไม่บอกว่าเป็นเพราะดวงอาทิตย์อยู่ต่ำ                                                                                                                               |
| 1     | บอกว่า "หลุมลึก" อย่างเดียว                                                                                                                                                              |
| 0     | ตอบว่าเพราะเงาโลก อยู่ด้านไกล หรือพื้นสีเข้ม                                                                                                                                             |

## ตอนที่ 4 คณิตศาสตร์ของขอบหลุม (ตัวเลขสมมุติ)

| ข้อ | คำตอบ                                                                                                |
| --- | ---------------------------------------------------------------------------------------------------- |
| 4.1 | tan θ = 2/20 = 0.1, θ ≈ 5.7°                                                                         |
| 4.2 | tan θ = 1.5/30 = 0.05, θ ≈ 2.9°                                                                      |
| 4.3 | **ไม่มีหลุมใด** เพราะมุมเงยของขอบหลุมทั้งสอง (5.7° และ 2.9°) มากกว่ามุมเงยสูงสุดของดวงอาทิตย์ (1.5°) |
| 4.4 | h = d × tan 1.5° = 30 × 0.0262 ≈ 0.79 กิโลเมตร ขอบหลุมต้องสูงไม่เกินประมาณ 0.8 กิโลเมตร              |
| 4.5 | `[รอค่าจากชุดข้อมูลบทเรียน]`                                                                         |

ยอมรับค่าที่ปัดเศษต่างกันเล็กน้อยตามเครื่องคิดเลขหรือตาราง

**หมายเหตุสำหรับครู:** ในแอป มุมเงยของเส้นขอบฟ้าคำนวณจากความสูงภูมิประเทศจริง (LOLA) ไกลถึง 200 กิโลเมตร
และคิดความโค้งของดวงจันทร์ด้วย จึงไม่ใช่ arctan(h/d) แบบสามเหลี่ยมเดียวตรง ๆ แต่หลักการเหมือนกัน
นอกจากนี้ ดวงอาทิตย์เป็นแผ่นกลม แอปคิดส่วนของแผ่นที่พ้นขอบฟ้า ไม่ได้คิดเฉพาะจุดกึ่งกลาง

## คำถามท้ายใบงาน

**เกณฑ์ (2 คะแนน)** 2 = ที่สูง เช่น ยอดเขาหรือสันเขา เพราะเส้นขอบฟ้ารอบตัวต่ำ ดวงอาทิตย์ที่อยู่ต่ำจึงยังส่องถึงได้เกือบตลอด
1 = ตอบ "ที่สูง" โดยไม่มีเหตุผล 0 = ตอบพื้นหลุมหรือที่ต่ำ
