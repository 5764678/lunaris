## ตอนที่ 1 คำทำนาย

ไม่ให้คะแนนความถูกต้อง คำตอบที่คาดหวังหลังเรียน: กรุงเทพฯ ดวงอาทิตย์ขึ้นทางตะวันออก ขึ้นสูงกลางวัน ตกทางตะวันตก
ขั้วใต้ของดวงจันทร์ ดวงอาทิตย์วนรอบขอบฟ้าอยู่ต่ำมาก ใช้เวลาประมาณหนึ่งเดือนของโลกต่อหนึ่งรอบ

## ตอนที่ 2 อ่านแผนภูมิท้องฟ้า

- 2.1 ดูตารางข้างบน ข้อสังเกตที่ต้องได้: ดวงอาทิตย์อยู่ต่ำมาก ไม่เกินไม่กี่องศาจากแนวราบตลอดรอบเดือน
- 2.2 **วนรอบขอบฟ้าอยู่ต่ำ ๆ**
- 2.3 **มี** ทุกจุด (ดูตาราง) ที่ยอดเขาใกล้แชคเคิลตัน ช่วงที่มองไม่เห็นเกิดเพราะดวงอาทิตย์ลงต่ำกว่าเส้นขอบฟ้า ที่สันเขาเชื่อมต่อเกิดเพราะภูเขาบังทั้งหมด
- 2.4 ดูตาราง ข้อสังเกตที่ต้องได้: โลกอยู่ต่ำใกล้ขอบฟ้า ขึ้นลงไม่เกินราว 10° และอยู่ในทิศแคบ ๆ ประมาณ 15°
- 2.5 ดวงอาทิตย์วนไปรอบทุกทิศ ส่วนโลกอยู่ในทิศเกือบเดิม ขยับขึ้นลงเพียงเล็กน้อย
  เพราะดวงจันทร์หันด้านเดียวเข้าหาโลก (หมุนรอบตัวเองหนึ่งรอบต่อการโคจรรอบโลกหนึ่งรอบ)
  การที่โลกขยับขึ้นลงเล็กน้อยเกิดจากการแกว่งของดวงจันทร์ (ไม่ต้องให้นักเรียนรู้ชื่อนี้)

## ตอนที่ 3 เมื่อภูมิประเทศบังหรือช่วยให้เห็นดวงอาทิตย์

ค่าในตารางของใบงาน: ขอบฟ้าราบ = `illumination.astronomical.illuminated_fraction` คิดภูมิประเทศ = `illumination.terrain.illuminated_fraction`
(`timeline.json` ของแต่ละจุด) อามุนด์เซน 1 = `shadowed_scan` ใน `manifest.json` ซึ่งตรวจทั้ง 24 จุดที่ไม่ใช่จุดสาธิต
และ**ไม่พบจุดที่ได้รับแสง 0 %** ในรอบเดือนนี้ (`permanently_shadowed_example: null`) จุดสาธิตทั้งสามก็ไม่เป็น 0 %

- 3.1 **สันเขาเชื่อมต่อ** (100.0 % → 91.5 %) ภูเขาในทิศราวทิศเหนือ (359°–29°) สูงกว่าดวงอาทิตย์ จึงบังแสงประมาณ 61 ชั่วโมง
- 3.2 **ยอดเขาใกล้แชคเคิลตัน** (67.7 % → 96.2 %) และ**เทือกเขามาลาเพิร์ต** (56.0 % → 65.8 %) ผู้สังเกตอยู่สูงกว่าพื้นรอบ ๆ
  เส้นขอบฟ้าจึงต่ำกว่าแนวราบในบางทิศ (ต่ำสุด −3.1° และ −4.8°) เห็นดวงอาทิตย์ได้แม้ดวงอาทิตย์ลงต่ำกว่าแนวราบเล็กน้อย
- 3.4 **การคำนวณ** (`evidence.kind` = `calculation`) ตรวจกับคำที่หน้าจอแอปใช้
- 3.3 **เกณฑ์ (3 คะแนน)**

| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
