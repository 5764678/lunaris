## 3. หมายเหตุรายข้อ

- **ข้อ 8** คำตอบ "หันลงไปทางที่ดวงอาทิตย์เพิ่งตก" ถูกต้องสำหรับผู้สังเกตทุกแห่ง เพราะด้านสว่างหันหาดวงอาทิตย์เสมอ
  ข้อนี้ไม่ได้ใช้ภาพจากแอป เพราะแอปแสดงภาพมองจากจุดศูนย์กลางโลก ทิศเหนืออยู่ด้านบน ไม่ใช่ท้องฟ้าของประเทศไทย
- **ข้อ 10** ตัวเลข "ประมาณ 50 นาที" เป็นค่าเฉลี่ยตามหนังสือเรียน ครูตรวจกับหนังสือเรียน สสวท. ก่อนใช้
- **ข้อ 13** วัดเฉพาะน้ำเกิด ซึ่งสอนด้วยกิจกรรม unplugged ในคาบที่ 3 แอปไม่มีแบบจำลองน้ำขึ้นน้ำลง
- **ข้อ 15** ค่าประมาณ 29.5 วันเป็นความยาวเฉลี่ยของรอบข้างขึ้นข้างแรม ครูตรวจตัวเลขกับหนังสือเรียน
- **ข้อ 17 และ 19** ใช้ตัวเลขสมมุติซึ่งระบุไว้ในข้อสอบ
- **ข้อ 18** คำว่า "ทิศเกือบเดิม" ถูกต้องในระดับ ม.3 รายละเอียดเรื่องการแกว่งของดวงจันทร์ไม่ต้องใช้ในการตอบ
