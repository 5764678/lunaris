# เฉลยใบงานที่ 1 สำรวจข้างขึ้นข้างแรมหนึ่งรอบเดือน (สำหรับครู)

**ค่าที่รอจากชุดข้อมูลบทเรียน (ยังไม่มีค่า ห้ามประมาณ)**

| จุด                         | ค่าที่ต้องเติม                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------ |
| ตอนที่ 2 แถว 1–8            | วันที่ ร้อยละของส่วนสว่าง ข้างขึ้น/ข้างแรม ชื่อข้างขึ้นข้างแรม `[รอค่าจากชุดข้อมูลบทเรียน]` |
| ข้อ 2.1                     | เลขแถวที่สว่างมากที่สุดและน้อยที่สุด `[รอค่าจากชุดข้อมูลบทเรียน]`                     |
| ข้อ 2.3                     | เลขแถวที่ตรงกับแต่ละตำแหน่ง `[รอค่าจากชุดข้อมูลบทเรียน]`                              |
| ข้อ 4.1–4.2                 | ค่ำในปฏิทินจันทรคติฉบับที่ครูแจก (ครูอ่านจากปฏิทินจริง แอปไม่ได้คำนวณ)                 |

**ข้อเสนอการเลือกวันที่ 8 แถว (ให้ S-LESSONDATA หรือครูเลือกจากชุดข้อมูลจริง):**
ใกล้จันทร์ดับ 1 แถว ระหว่างจันทร์ดับกับครึ่งดวง 1 แถว ใกล้ข้างขึ้นครึ่งดวง 1 แถว ระหว่างครึ่งดวงกับจันทร์เพ็ญ 1 แถว
ใกล้จันทร์เพ็ญ 1 แถว และฝั่งข้างแรมอีก 3 แถวในลักษณะเดียวกัน เรียงตามวันที่

## ตอนที่ 1 คำทำนาย

ไม่มีคำตอบผิด ให้คะแนนการตอบครบ คำตอบที่คาดหวังเพื่อใช้ในตอนที่ 3:

- 1.1 ถ้าเงาโลกเป็นสาเหตุ ดวงจันทร์ด้านตรงข้ามดวงอาทิตย์ควร**มืดหรือเกือบมืด**
- 1.2 แบบจำลองแสดงลูกบอล**สว่างเต็มดวง** (ถ้ายกลูกบอลพ้นเงาศีรษะ)

## ตอนที่ 2 บันทึกข้อมูล

- ค่าในตารางต้องตรงกับค่าที่แอปแสดง `[รอค่าจากชุดข้อมูลบทเรียน]` ยอมรับการปัดเศษเป็นจำนวนเต็ม
- รูปร่างที่วาด: ส่วนสว่างเพิ่มจากด้านขวาในช่วงข้างขึ้น และเหลือด้านซ้ายในช่วงข้างแรม (ภาพในแอปทิศเหนืออยู่ด้านบน)
- 2.2 ร้อยละของส่วนสว่าง**เพิ่มขึ้นทีละน้อย**อย่างต่อเนื่อง ไม่กระโดด
- 2.3 ระหว่างหลอดไฟกับศีรษะ = แถวที่ใกล้จันทร์ดับ, ส่วนสว่างด้านขวา = ใกล้ข้างขึ้นครึ่งดวง,
  ตรงข้ามหลอดไฟ = ใกล้จันทร์เพ็ญ, ส่วนสว่างด้านซ้าย = ใกล้ข้างแรมครึ่งดวง
  (ถ้านักเรียนหันตัวในทิศต่างออกไปตอนทำแบบจำลอง ด้านซ้าย/ขวาอาจสลับ ให้ครูตรวจจากเหตุผล)

## ตอนที่ 3 ทดสอบสมมติฐาน

**3.1** หักล้าง

**3.2 เกณฑ์ให้คะแนน (3 คะแนน)**

| คะแนน | ลักษณะคำตอบ                                                                                                                         |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 3     | อ้างแถวจันทร์เพ็ญ: ตอนที่ดวงจันทร์อยู่ด้านตรงข้ามดวงอาทิตย์ (ตำแหน่งที่เงาโลกชี้ไป) ดวงจันทร์กลับสว่างมากที่สุด ร้อยละ ...... (ค่าจริงจากแถว) |
| 2     | บอกว่าข้อมูลขัดกับสมมติฐาน แต่ไม่อ้างแถวหรือค่าที่ชัดเจน                                                                           |
| 1     | ตอบว่าหักล้างโดยไม่มีเหตุผล                                                                                                          |
| 0     | ตอบว่าสนับสนุน หรือไม่ตอบ                                                                                                            |

**3.3** ประมาณมุมฉาก (90°) เงาของโลกชี้ออกไปในทิศตรงข้ามดวงอาทิตย์ จึง**ไปไม่ถึง**ดวงจันทร์ที่อยู่ด้านข้าง
แต่ดวงจันทร์ก็ยังเห็นครึ่งดวง แสดงว่าส่วนมืดไม่ได้เกิดจากเงาโลก

## ตอนที่ 4 เทียบกับปฏิทินจันทรคติ

- 4.1–4.2 ครูตรวจกับปฏิทินฉบับที่แจก โดยทั่วไปวันที่สว่างมากที่สุดอยู่ใกล้ขึ้น 14–15 ค่ำ และวันที่มืดที่สุดอยู่ใกล้แรม 14–15 ค่ำ
  หรือขึ้น 1 ค่ำ แต่**ไม่จำเป็นต้องตรงพอดี**
- 4.3 แนวคำตอบที่ยอมรับ (ข้อใดข้อหนึ่ง):
  - ปฏิทินจันทรคตินับวันเป็นวันเต็ม ๆ ตามข้อตกลงของปฏิทิน ส่วนจันทร์เพ็ญทางดาราศาสตร์เป็นเพียง "ขณะหนึ่ง"
    ซึ่งอาจตกในวันก่อนหรือหลังวันที่ปฏิทินเรียกว่าขึ้น 15 ค่ำ
  - เดือนทางจันทรคติมี 29 หรือ 30 วันตามการจัดปฏิทิน แต่รอบข้างขึ้นข้างแรมจริงไม่ได้ยาวเป็นจำนวนวันเต็มพอดี
  - เวลาที่แอปใช้กับเวลาที่ปฏิทินเริ่มนับวันอาจต่างกัน
- **ไม่ยอมรับ** คำตอบว่า "แอปผิด" หรือ "ปฏิทินผิด" โดยไม่มีเหตุผล สองอย่างนี้บอกคนละเรื่อง:
  แอปคำนวณส่วนสว่างทางดาราศาสตร์ ปฏิทินเป็นวิธีนับวัน
- ครูอาจชี้ว่าวันพระในปฏิทินก็ใช้วิธีนับนี้ ซึ่งเป็นเรื่องวัฒนธรรมที่ไม่ได้ผิดทางวิทยาศาสตร์ แต่ไม่ใช่การวัดดวงจันทร์

## บัตรออก

ไม่ให้คะแนน ครูอ่านเพื่อดูว่ายังมีนักเรียนที่ยึดคำอธิบายเงาโลกหรือไม่ แล้วเน้นจุดนั้นในคาบที่ 3
