# เฉลยใบงานที่ 3 ทีมภารกิจเปรียบเทียบจุดลงจอด (สำหรับครู)

**ค่าที่รอจากชุดข้อมูลบทเรียน (ยังไม่มีค่า ห้ามประมาณ)**

| จุด            | ค่าที่ต้องเติม                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------ |
| ตอนที่ 1       | ค่าทั้ง 21 ช่อง (7 ค่า × 3 จุด) พร้อมหน่วย และชนิดป้ายหลักฐานของแต่ละแถว `[รอค่าจากชุดข้อมูลบทเรียน]`              |
| ตอนที่ 2.1     | ขึ้นกับค่าที่นักเรียนเลือก ครูตรวจกับหน้าจอจริง                                                                    |
| ตอนที่ 4.2–4.4 | คำแนะนำเริ่มต้น เหตุผล สิ่งที่ต้องยอมเสีย และสิ่งที่ทำให้คำแนะนำเปลี่ยน ตามที่แอปแสดง `[รอค่าจากชุดข้อมูลบทเรียน]` |
| ตอนที่ 5       | ค่าสรุปห้าตัวเลขและคำตอบข้อ 5.2 `[รอค่าจากชุดข้อมูลบทเรียน]`                                                       |

**ข้อมูลเชิงคุณภาพที่มีอยู่แล้ว** (จาก `docs/API.md` และ `README.md` ของโครงการ ฉบับหลังการแก้ไข D9 วันที่ 14 พ.ย. 2569
สำหรับสามจุดสาธิตปี 2570 ต้องตรวจซ้ำกับชุดข้อมูลบทเรียนเมื่อมาถึง):

- ไม่มีจุดใดดีที่สุดทุกค่า ยอดเขาใกล้แชคเคิลตันนำเรื่องความชัน แสงอาทิตย์และช่วงมืด และการมองเห็นโลก แต่ขรุขระที่สุด
  สันเขาเชื่อมต่อนำเรื่องช่วงได้รับแสงต่อเนื่องนานที่สุด แต่ชันที่สุด
  เทือกเขามาลาเพิร์ตนำเรื่องความขรุขระ แต่แย่ที่สุดเรื่องแสงอาทิตย์และช่วงมืด การมองเห็นโลก และช่วงได้รับแสงต่อเนื่องนานที่สุด
- คำแนะนำเริ่มต้น (ทุกเรื่อง "สำคัญ" ไม่มีข้อจำกัดบังคับ): ยอดเขาใกล้แชคเคิลตัน นำห่างชัดเจน
- ถ้านับเฉพาะการลงจอด (พลังงานและการสื่อสาร "ไม่จำเป็น" การลงจอด "สำคัญมาก"): เทือกเขามาลาเพิร์ต นำเพียงเล็กน้อย
- ถ้าตั้งข้อจำกัดความชันสูงสุด 5 องศา: เหลือยอดเขาใกล้แชคเคิลตันเพียงจุดเดียว

## ตอนที่ 1

ทิศทางที่ "ดีกว่า" (ตามที่แอประบุในแต่ละคอลัมน์):

| ค่า                             | ค่าที่ดีกว่า | เหตุผลสั้น ๆ                           |
| ------------------------------- | ------------ | -------------------------------------- |
| ความชันที่จุด                   | ต่ำ          | ลงจอดและตั้งอุปกรณ์ได้ปลอดภัยกว่า      |
| ความขรุขระ                      | ต่ำ          | พื้นเรียบ เสี่ยงน้อยกว่า               |
| สัดส่วนเวลาที่ได้รับแสง         | สูง          | ผลิตพลังงานแสงอาทิตย์ได้นานกว่า        |
| ช่วงมืดนานที่สุด                | ต่ำ          | แบตเตอรี่ต้องเก็บพลังงานน้อยกว่า       |
| ช่วงได้รับแสงต่อเนื่องนานที่สุด | สูง          | ทำงานด้วยแสงอาทิตย์ได้ต่อเนื่องนานกว่า |
| สัดส่วนเวลาที่มองเห็นโลก        | สูง          | มีโอกาสสื่อสารตรงกับโลกนานกว่า         |
| ช่วงมองไม่เห็นโลกนานที่สุด      | ต่ำ          | ขาดการติดต่อสั้นกว่า                   |

ค่าในช่องและชนิดป้ายหลักฐาน: `[รอค่าจากชุดข้อมูลบทเรียน]`

## ตอนที่ 2

- 2.1 ตรวจว่าชนิดหลักฐาน แหล่งข้อมูล และข้อจำกัดตรงกับที่แอปแสดง ข้อจำกัดที่พบบ่อย เช่น
  "การมองเห็นโลกเป็นเชิงเรขาคณิต ไม่ใช่การสื่อสารทางวิทยุ" หรือช่วงเวลาที่ใช้คำนวณ
  (ข้อความข้อจำกัดในแอปอาจเป็นภาษาอังกฤษ นักเรียนแปลความหมายเป็นไทยได้)
- 2.2 การสังเกต = ค, แบบจำลอง = ง, การคำนวณ = ก, ข้อสมมุติ = ข

## ตอนที่ 3

- 3.1 **ไม่มี**
- 3.2 **ไม่มี** (สันเขาเชื่อมต่อไม่นำค่าใดแต่ไม่ถูกครอบงำ เพราะดีกว่าจุดอื่นอย่างน้อยหนึ่งค่าในการเทียบแต่ละคู่) ตรวจซ้ำกับชุดข้อมูลบทเรียน
- 3.3 ยอมรับข้อแลกเปลี่ยนที่ตรงกับตาราง เช่น "ยอดเขาใกล้แชคเคิลตันดีกว่าเรื่องแสงอาทิตย์ แต่แย่กว่าเรื่องความขรุขระ"
  หรือ "เทือกเขามาลาเพิร์ตเรียบกว่า แต่ได้รับแสงน้อยกว่าและเห็นโลกน้อยกว่า"

## ตอนที่ 4

- **4.1** ไม่มีคำตอบเดียวที่ถูก ทีมต้องตัดสินใจเองก่อนดูคำแนะนำ ให้คะแนนตามเหตุผล (ดูตารางเกณฑ์ข้างล่าง)
- **4.2** คำแนะนำเริ่มต้น: ยอดเขาใกล้แชคเคิลตัน (ตรวจกับชุดข้อมูลบทเรียน) ความสำคัญเริ่มต้นคือทุกเรื่อง "สำคัญ" และไม่มีข้อจำกัดบังคับ
  น้ำหนักและเกณฑ์ติดป้าย **ข้อสมมุติ** ประเด็นที่ต้องได้: คำแนะนำนี้ออกมาแม้ยังไม่มีใครบอกว่าภารกิจต้องการอะไร
  น้ำหนักจึงเป็นข้อสมมุติของ LUNARIS ไม่ใช่ความต้องการของภารกิจ
- **4.3** ขึ้นกับคำตอบของทีม ตรวจว่าบันทึกตรงกับที่แอปแสดง `[รอค่าจากชุดข้อมูลบทเรียน]`
  ถ้าทีมเลือกการลงจอด "สำคัญมาก" และอีกสองเรื่อง "ไม่จำเป็น" แอปควรแนะนำเทือกเขามาลาเพิร์ต
- **4.4 ก** ข้อมูลที่วัดหรือคำนวณ: ความชัน ความขรุขระ แสงอาทิตย์ การมองเห็นโลก (ป้ายการคำนวณหรือผลิตภัณฑ์ข้อมูลตามที่แอปแสดง)
  ข้อสมมุติ: ระดับความสำคัญที่แปลงเป็นน้ำหนัก สเกลอ้างอิงที่ใช้ให้คะแนน และข้อจำกัดบังคับที่ตั้ง
- **4.4 ข** ยอมรับทั้งเห็นด้วยและไม่เห็นด้วย ถ้าอ้างค่าจากตอนที่ 1 ได้ถูกต้อง
  **ไม่ยอมรับ** เหตุผลว่า "เห็นด้วยเพราะแอปบอก" (คำแนะนำไม่ใช่คำตอบที่ถูกเสมอ)
- **4.4 ค** ตรวจกับส่วน "สิ่งที่จะทำให้คำแนะนำเปลี่ยน" ที่แอปแสดง ถ้าคำแนะนำไม่เปลี่ยน ก็เป็นคำตอบที่ถูกได้
  ข้อสังเกตที่ดี: คำแนะนำที่ไม่เปลี่ยนเมื่อขยับความสำคัญ 1 ระดับ น่าเชื่อถือกว่าคำแนะนำที่เปลี่ยนง่าย
- **4.5** ให้คะแนนความสอดคล้องระหว่างความต้องการในข้อ 4.1 กับจุดที่เสนอ:

| คะแนน | ลักษณะคำตอบ                                                                                                    |
| ----- | -------------------------------------------------------------------------------------------------------------- |
| 3     | ความต้องการมีเหตุผลที่โยงกับภารกิจ และจุดที่เสนอสอดคล้องกับความต้องการและค่าในตาราง (ตรงหรือไม่ตรงกับแอปก็ได้) |
| 2     | ความต้องการมีเหตุผล แต่จุดที่เสนอไม่สอดคล้องกับความต้องการชัดเจน                                               |
| 1     | เลือกจุดตามคำแนะนำของแอปโดยไม่มีเหตุผลของทีมเอง                                                                |
| 0     | ไม่ตอบ                                                                                                         |

## ตอนที่ 5 (ส่วนขยาย)

`[รอค่าจากชุดข้อมูลบทเรียน]` คำตอบที่คาดหวังเชิงหลักการ: จุดที่มีเส้นขอบฟ้าต่ำโดยรวมมักได้รับแสงอาทิตย์ได้นานกว่า
เพราะดวงอาทิตย์ที่ขั้วอยู่ต่ำใกล้ขอบฟ้า แต่ความสัมพันธ์ไม่จำเป็นต้องสมบูรณ์ เพราะสิ่งที่สำคัญคือเส้นขอบฟ้า**ในทิศที่ดวงอาทิตย์ผ่าน**
